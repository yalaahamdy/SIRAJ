# 05 — دليل التطوير والاختبارات والبناء (Development & Testing)

يوضح هذا الدليل المعايير الهندسية الصارمة، خطوات التحقق والتحليل، ومصفوفة الاختبارات الآلية لبناء حزم الإنتاج الموقعة لتطبيق **سِراج**.

---

## 🛡️ القيود والمعايير الهندسية (Architectural Guardrails)
1. **قيد عدم الاعتماد على الشبكة في المهام الشرعية الأساسية**:
   - يُمنع منعاً باتاً وضع أي اتصال بالإنترنت كشرط مسبق لعرض القرآن أو الأذكار أو حساب الصلاة.
2. **منع استهلاك الذاكرة في فك الملفات (Zero Memory Spikes)**:
   - يجب أن تتم جميع عمليات فك ضغط واستخراج ملفات الصوت عبر تدفق من القرص للقرص (`InputFileStream` / `OutputFileStream`) وتفريغ ذاكرة التخزين المؤقت فوراً بعد كل ملف (`file.clear()`).
3. **سلامة اتصال الخط العربي (HarfBuzz Ligature Preservation)**:
   - يُمنع تكسير الكلمات القرآنية أو تطبيق أوزان خطوط متباينة (`FontWeight.bold`) داخل الكلمة الواحدة لتفادي انفصال الحروف.

---

## 🧪 مصفوفة الاختبارات الآلية (Automated Test Suite)
يشتمل المشروع على منظومة اختبارات تغطي كافة المستويات:

```bash
# تشغيل كامل مصفوفة الاختبارات
flutter test
```

### الوحدات المختبرة:
- **`test/modules/quran/quran_offline_audio_service_test.dart`**:
  - اختبار استيراد حزم ZIP للتلاوة الصوتية بنظام التدفق.
  - فحص التحقق من وجود ملفات MP3 والتعامل مع الملفات التالفة أو الفارغة.
  - اختبار مسارات التخزين المحلي وحذف التخزين المؤقت.
- **`test/shell/quran_reader_screen_test.dart`**:
  - اختبار عرض السور، قائمة الآيات، الفواصل المرجعية، وشريط البحث.
- **`test/shell/quran_audio_radio_and_features_test.dart`**:
  - اختبار مشغل التلاوة والإذاعة القرآنية والتبويبات الفرعية.

## 🔍 التحليل الساكن وضبط الجودة (Static Analysis)
قبل أي عملية بناء أو تسليم، يجب التأكد من خلو المشروع تماماً من أي أخطاء أو تحذيرات:

```bash
flutter analyze
```
> **النتيجة المطلوبة**: `No issues found! (0 errors, 0 warnings)`

## 📦 بناء حزمة الإنتاج النهائية (Production APK Build)
لبناء حزمة أندرويد رسمية جاهزة للنشر والتثبيت المباشر على كافة الهواتف:

```bash
flutter build apk --release
```
- **مسار مخرج الحزمة**: `build/app/outputs/flutter-apk/app-release.apk`
- **التوافق**: Android 6.0 (API 23) فما فوق، معماريات `arm64-v8a`, `armeabi-v7a`, `x86_64`.
