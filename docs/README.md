## 🌟 المبادئ الهندسية والشرعية الأساسية (Core Pillars)
1. **الاستقلالية والعمل بدون إنترنت (100% Offline-First)**:
   - لا يعتمد التطبيق على أي خادم خارجي لتأدية وظائفه الشرعية الأساسية (المصحف، المواقيت، القبلة، الأذكار، والتفسير).
2. **سلامة وموثوقية البيانات الشرعية (Sacred Canonical Data Integrity)**:
   - كافة النصوص القرآنية، مواقيت الصلاة، الأذكار، والترجمات مخزنة محلياً بصيغ معتمدة وغير قابلة للعبث، وتعمل بمبدأ الإغلاق عند الفشل (Fail-Closed Integrity).
3. **التصميم الإسلامي المتقن وتجربة المستخدم الراقية (Islamic Aesthetics & Polish)**:
   - مراعاة أدق التفاصيل في رسم الخطوط العثمانية، الزخارف الإسلامية والأندلسية الأصيلة، والتجاوب الكامل مع كافة قياسات الشاشات.
