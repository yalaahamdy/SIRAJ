# سِراج (SIRAJ) — المنظومة الإسلامية الشاملة والمستقلة (v1.0)
> **تطبيق إسلامي شامل، متكامل، ومستقل تماماً، يعمل بدون إنترنت (100% Offline-First)، مبني بأعلى المعايير الهندسية والبرمجية والأصالة العلمية والشرعية.**

---

## 📖 نظرة عامة على المشروع (Executive Summary)

مشروع **سِراج (SIRAJ)** هو منصة إسلامية متكاملة تهدف إلى تقديم تجربة رقمية إسلامية فريدة تجمع بين **الأصالة الشرعية المطلقة** و**التميز الهندسي والتقني**. صُمم التطبيق ليكون رفيقاً يومياً للمسلم في عباداته وقراءته للقرآن الكريم، ومتابعة أذكاره، وتحديد مواقيت صلاته واتجاه القبلة، وحفظ ومراجعة كتاب الله، دون أي اعتماد على خوادم خارجية أو اتصال دائم بشبكة الإنترنت.

### المبادئ الهندسية والشرعية الحاكمة (Core Pillars):
1. **الاستقلالية والعمل بدون إنترنت (100% Offline-First)**:
   - كافة الوظائف الحيوية (المصحف بالرسم العثماني، التفاسير، الترجمات الـ 11، حساب مواقيت الصلاة الفلكية، محرك زاوية القبلة، الأذكار الصحيحة، ونظام التحفيظ) تعمل محلياً بالكامل ومسبقة التضمين في التطبيق.
2. **النزاهة الشرعية والإغلاق عند الفشل (Sacred Canonical Data Integrity)**:
   - كافة النصوص والبيانات الشرعية مستندة إلى مصادر ومخطوطات موثوقة (مصحف المدينة المنورة، حصن المسلم)، ويتم فحص ومطابقة بصماتها المشفرة (SHA-256) لمنع أي تحريف أو عبث برمجي.
3. **الأداء العالي وإدارة الذاكرة الصارمة (Zero-RAM Leak & Streaming I/O)**:
   - معالجة وفك ضغط حزم التلاوات الصوتية الضخمة (التي تتجاوز 1.5 جيجابايت) عبر التدفق المباشر من القرص للقرص (Disk-to-Disk Streaming)، مما يضمن استهلاك ذاكرة لا يتجاوز 5 ميجابايت على كافة أجهزة الهواتف الذكية.
4. **الجماليات والتصميم الإسلامي الراقي (Islamic Aesthetics & Visual Polish)**:
   - تصميم واجهات مستوحى من الفن والزخرفة الإسلامية والأندلسية، مع توفير 3 سمات بصرية متكيفة (السمة الفاتحة العاجية، سمة ورق المصحف النبوي السيبيا، والسمة الداكنة الليلية الخاشعة).

## 🚀 دليل البدء السريع للمطورين (Developer Quick Start)

### المتطلبات المسبقة:
- **Flutter SDK**: الإصدار `3.24.x` أو أحدث.
- **Dart SDK**: الإصدار `3.5.x` أو أحدث.
- **Android SDK**: API Level 34 (Android 14) مع حد أدنى API Level 23 (Android 6.0).

### الأوامر الأساسية:
```bash
# 1. استرجاع الحزم والاعتماديات
flutter pub get

# 2. التحقق من سلامة الكود وخلوه من التحذيرات
flutter analyze

# 3. تشغيل مصفوفة الاختبارات الآلية
flutter test

# 4. تشغيل التطبيق في وضع التطوير
flutter run

# 5. بناء حزمة الإنتاج الرسمية للأندرويد
flutter build apk --release
```
